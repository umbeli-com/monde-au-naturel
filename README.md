# Le Monde au Naturel

Site vitrine multi-pages du **Monde au Naturel** — distributeur de produits naturels établi à Trois-Rivières depuis 1990.

## Pages

- `index.html` — Accueil
- `boutique.html` — Boutique en ligne (7 000+ produits)
- `guide.html` — Guide santé (avec flipbook PDF interactif)
- `commercants.html` — Espace B2B
- `apropos.html` — Notre histoire
- `contact.html` — Contact + formulaire

## Tech

Pages HTML statiques, CSS inline, JavaScript vanilla. Flipbook propulsé par [StPageFlip](https://github.com/Nodlik/StPageFlip) + [PDF.js](https://mozilla.github.io/pdf.js/).

## Hébergement

Déployé via **GitHub Pages** sur la branche `main`.
